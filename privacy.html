Privacy Policy

Tab Setu helps you save, search, organize, and restore browser tabs while keeping your data local whenever possible.

Last updated: May 14, 2026

Overview

Tab Setu is a browser extension for tab and session management. Its single purpose is to help users manage open tabs, saved sessions, notes, reminders, search, overlay access, and related tab productivity workflows.

Tab Setu does not sell user data, does not use user data for advertising, and does not share user data with third parties for unrelated purposes.

Data Tab Setu may access or use

Depending on which features you use, Tab Setu may access or store the following data:

  • Tab information: tab titles, URLs, favicons, active tab state, and browser window information used for tab search, switching, saving, restoring, and organizing sessions.
  • Browser history: page titles, URLs, and visit-related information used only to provide history search and reopening of previously visited pages.
  • Website content: page text may be accessed only when a feature such as page text extraction or AI prompt generation is used. This is used to generate user-requested context and is not used for advertising, tracking, or profiling.
  • User-created content: saved sessions, folders, tags, notes, reminders, schedules, exported sessions, and extension preferences created by the user.
  • Extension settings: theme choice, overlay state, search preferences, reminder settings, and other configuration needed to restore the user’s chosen experience.

How data is used

Tab Setu uses data only to provide its core extension features, including:

  • Displaying and searching open tabs.
  • Saving, restoring, organizing, importing, and exporting browser sessions.
  • Searching browser history when the user uses history search.
  • Showing the Tab Setu overlay on supported websites.
  • Saving user preferences such as theme, overlay state, and extension settings.
  • Supporting reminders, schedules, notes, and user-requested tab workflows.
  • Generating context-rich prompts from selected tabs or page text when the user chooses to use that feature.

Local storage and retention

Tab Setu stores extension data locally in the browser using browser extension storage mechanisms. This may include saved sessions, notes, folders, tags, reminders, schedules, and user preferences.

Data remains stored until the user deletes it, clears browser extension data, resets extension storage, or uninstalls the extension.

Data sharing

Tab Setu does not sell, rent, or transfer user data to third parties for advertising, tracking, profiling, lending, creditworthiness, or unrelated purposes.

If the user manually exports a session, shares a session link, copies an AI prompt, or sends content to another application or service, the user controls what is shared and where it is sent.

AI-related features

Tab Setu may help users generate prompts from selected tabs, saved sessions, or page text. Tab Setu does not automatically send page content, tab data, or history data to external AI providers. If a user copies, exports, or submits generated content to another service, that service’s own privacy practices apply.

Remote code

Tab Setu does not use remote code in the browser extension. JavaScript, CSS, and executable extension resources are included in the extension package.

Permissions

Tab Setu requests browser permissions only to support its tab management functionality:

  • tabs: to read and manage open tabs for search, switching, saving, and restoring sessions.
  • storage: to save user preferences, sessions, notes, reminders, schedules, and extension settings.
  • history: to let users search and reopen previously visited pages.
  • scripting and activeTab: to show and manage the Tab Setu overlay on supported pages when the user uses the feature.
  • host permissions: to allow the overlay/content script to run on supported websites where the extension is allowed to operate.
  • alarms: to support reminders, schedules, and time-based tab workflows.
  • notifications: to show user-facing reminders or relevant extension alerts.
  • contextMenus: to provide quick access to Tab Setu actions from the browser right-click menu.

Restricted pages

Browser extensions cannot run on certain restricted pages, such as browser settings pages, extension store pages, and other protected browser URLs. Tab Setu respects these browser restrictions.

Children’s privacy

Tab Setu is not designed to knowingly collect personal information from children. The extension is intended for general tab and session management use.

Changes to this policy

This privacy policy may be updated if Tab Setu’s features, permissions, or data practices change. The updated version will be published on this page.
